# Sanya Keshri - Portfolio (plain HTML, CSS, JS)

No install or build step. Double-click `index.html` to open it.

## Files
- `index.html` - all the content
- `style.css` - colors and layout (variables at the top)
- `script.js` - animations and interactions
- `images/photo.jpg` - your photo
- `Sanya_Keshri_CV.pdf` - the CV used by the Download CV buttons

## LinkedIn
Search `index.html` for `linkedin.com/search` (2 places) and replace with your profile URL.

## Host on GitHub Pages (free)
1. Upload all these files to your repo (branch `main`).
2. Settings > Pages > Source: **Deploy from a branch** > Branch: `main`, folder `/ (root)` > Save.
3. Wait 1-2 minutes: https://YOUR-USERNAME.github.io/REPO-NAME/
